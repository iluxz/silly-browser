the silly browser

makes any website a little sillier. visual only, your screen only.

what is it?.

a tiny desktop app (python + tkinter) that runs a local server on localhost:8742. you write a javascript snippet in the app, click copy bookmarklet, and paste it as a bookmark in any browser. click that bookmark on any website and your script runs on that page — only on your screen, nothing changes for anyone else.

works in edge, firefox, chrome, whatever. no extensions, no store submissions, no chromium-only nonsense (family-safety friendly).

🎉 confetticlick anywhere → confetti explosion
🌈 rainbow modeslowly shifts the whole page through hues
🌊 floating elementseverything gently bobs up and down
💬 meme textreplaces words with silly versions
✨ cursor trailcolourful dots follow your cursor
shaken screen-shakethe page trembles every 3 seconds
🎲 defaulta little hello from the cube

download.

⬇ download the installer ⬇ download the .exe 📁 source code
how to use: run the exe → pick a script → MAKE IT SILLY → paste the bookmarklet into any browser → click it on any website. there's a playground button too, for testing.

quick start.

  1. open the silly browser
  2. pick a script (or write your own in the editor)
  3. hit MAKE IT SILLY (saves + copies the bookmarklet)
  4. paste the bookmarklet as a bookmark in any browser
  5. go to any website, click the bookmark
  6. your script runs on that page. only on your screen.

build it yourself.

pip install pyinstaller
pyinstaller --onefile --windowed --name "silly-browser" --icon silly.ico --add-data "scripts;scripts" --add-data "logo_small.png;." silly_browser.py
